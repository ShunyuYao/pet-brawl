# 桌宠大乱斗 · 规格 v0.5

形态沿用桌宠赛车：**单 HTML 作品**，局域网双人 / 单人对战电脑，自动带入当前桌宠。横版平台格斗，所有流派、招式、地图和数值都是本作自己的设计。

版本记录：
- v0.5：三张地图可选（§8）。
- v0.4：新增逗猫棒剑士、肉垫摔角手、拳击喵、疾风猫四个流派（§5B）。
- v0.3：新增猫爪拳、毛线球法师、纸箱忍者三个流派（§5A）。
- v0.2：键位改为 WASD；首个流派为奶酪大锤；加入时间上限；流派决定整张招式表（原因见 §4）。

## 1. 一句话玩法

横版浮空舞台，两只桌宠互殴。被打会累积**伤害百分比**，百分比越高被打得越远，飞出**场外边界**就少一条命。
默认每人 3 条命，**限时 8 分钟**，时间到时按剩余命数和百分比判胜负。开局先选**流派**，流派相当于人物，形象始终是你自己的桌宠。

## 2. 形象：2D 和 3D 共用同一套判定

| 来源 | 画面 | 条件 |
|---|---|---|
| 当前桌宠，宿主支持 `character.getRealtime` 且形象带布偶数据 | **3D 布偶**：每个招式有专门姿势，被重击打飞时切换成物理布偶翻滚 | 需要带 getRealtime 的宿主 |
| 当前桌宠，其他情况 | **2D 立绘**：idle 图做成面向镜头的平面，出招靠倾斜、压扁、突进、旋转，加上武器贴图和特效 | `character.getCurrent({states:['idle']})` |
| 普通浏览器、拒绝授权、电脑对手 | 内置玩具角色 | 无 |

- **形象和流派是两个独立的选择**：任何形象（3D 布偶、2D 立绘、内置玩具）都能选任何流派，流派在首页单独选择并记住；联机时双方各自选流派，随资料上报给房主。电脑对手每局换一个内置形象。
- **判定只由流派决定，与形象无关。** 同一流派无论 2D 还是 3D，受击范围和招式判定都完全相同。流派如果体型更大（例如大锤），就把形象按比例放大，让画面和判定一致。
- 读取流程与赛车相同（`pet-kart/src/main.js`）：`capabilities.request` → 先订阅变化、再读当前形象 → 优先尝试 getRealtime，拿不到就退回 2D → 查询联机邀请。拒绝授权时显示原因和「重新请求授权」按钮；对局中换装也会跟着换。
- 形象素材经 transfer 发给对方**一次**（3D 包重新编码到 ≤1 MB），对方收到后先校验（`checkAsset`）再渲染。
- 画面用 three.js 做 2.5D：侧视镜头，所有运动限定在一个竖直平面内。3D 布偶的招式姿势逐个身体部件做关键帧；只有被打飞时才交给 cannon-es 物理。物理只管画面，落点仍由规则层决定。

## 3. 键位

| 键盘 | 手柄 | 作用 |
|---|---|---|
| **A / D** | 左摇杆 | 左右移动；快速双击是冲刺 |
| **S** | 左摇杆↓ | 蹲下；在薄平台上按 S 会穿下去；空中按 S 快速下落 |
| **W** | 左摇杆↑ | 方向「上」；默认同时也是跳跃（「W 键跳跃」可以关掉） |
| **空格** | Ⓐ | 跳跃：轻点是短跳，按住是大跳；空中再按是多段跳 |
| **J** | Ⓧ | **普通攻击**（配合方向） |
| **K** | Ⓨ | **必杀技**（配合方向） |
| **U** | RB | **重击**（配合方向，按住蓄力） |
| **L** | LB | 盾；按住盾再按方向是闪避；空中按 L 是空中闪避 |
| **I**（或 L+J） | RT | 抓人 |

方向键 ↑↓←→ 作为备用移动键。

**起跳准备 3 帧**：按下跳跃后先有 3 帧准备才离地，准备结束时跳跃键已经松开就是短跳，还按着就是大跳。

**W 和攻击键同时按的规则**（键盘没有摇杆的轻推/猛推之分，所以这样定）：
- 由 **W** 触发的起跳，在 3 帧准备期内按 **J / U / K**，会取消跳跃，分别打出**上强 / 上重击 / 上必杀**。所以 W+J、W+U、W+K 都能稳定打出地面上的招式，不会先跳起来。空中的 W 二段跳同样有 3 帧窗口。
- 由 **空格** 触发的起跳不会被取消：空格后按 J 就是空中攻击（配合 W 就是上空）。

## 4. 招式结构

**流派拥有整张招式表**，而不是「普通攻击共用、流派只换必杀技」。「慢但重」是贯穿整个角色的设计：重型流派连普通攻击都要慢很多，如果普通攻击共用，轻型流派就会同时拥有快招和高重量，平衡会崩。

所有流派用同一套**按键结构**和同一组**动作模板**（画面复用）；帧数、伤害、击飞、判定范围和特殊属性各流派一张表。

每个流派的招式清单：

| 类别 | 招式 |
|---|---|
| 地面 | 普攻 1 → 2 → 终结 · 侧强 · 上强 · 下强 · 冲刺攻击 |
| 重击（U，按住蓄力，最多 60 帧，伤害 ×1.4） | 侧重击 · 上重击 · 下重击 |
| 空中 | 空中普攻 · 前空 · 上空 · 下空（不区分前空和后空，朝对手打就是前空） |
| 抓投 | 抓 · 前投 · 后投 |
| 必杀（K） | 通常 · 侧 · 上（复活技）· 下 |
| 起身 | 台边起身攻击、倒地起身攻击（共用模板） |

**击杀目标**是一个「受击前百分比」，测量口径固定为：
- 对手是同一流派，站在舞台中央地面上（注明「台边」的站在台边内侧 5 个单位处），不做任何操作；
- 招式是新鲜的（带 ×1.05 新鲜加成），攻击方 0%（没有怒气），重击不蓄力；
- **击飞轨迹**（击飞速度衰减到 0 之前）越过场外边界，就算击杀。之后因为不回场而自己掉下去的，不算。

§6 的公式需要「基础击飞」和「成长」两个参数，**实现时用脚本从目标值反推**：只有一个目标的招式固定基础击飞、反推成长；侧重击有中央和台边两个目标，两个参数一起解。「实测击杀百分比在目标 ±10% 以内」写进测试（见 §11 第 8 条）。**往下砸的招式（下空锤头中心、上 B 砸下）不设击杀百分比**：被砸下去能不能回来取决于对手的操作，测试只断言对手确实往下飞。

### 5A.4 平衡验证

- 每个流派的击杀百分比都用 §5.2 的口径由标定脚本反推，测试断言 ±10。
- **流派对局胜率**（`npm run balance`，`artifacts/balance.json`）：高手难度电脑两两对打（含镜像），每组 **200 局**、先后手轮换。任何一组胜率落在 25%–75% 之外就判失败。每组只打 16 或 40 局时，噪声大到换一下先后手胜率就差 12 个百分点，据此调数值会被噪声带着走，所以固定 200 局。

4. 统计丢命原因发现大量回场失败：忍者一律斜 45° 弹射够不到台边；大锤大跳起点在台外时笔直砸进深渊。电脑改为瞄准台边上方选弹射方向、按预测落点决定是否取消大跳转为无助下落飘回台边。这一步让三个新流派之间都回到 48%–54%。
5. 大锤仍偏弱（31%–36%）。体重恢复到 127 后对猫、忍者回到 40% 左右。大锤对法师 30.5% 保留：慢速重型被远程牵制克制是格斗游戏里常见的克制关系，且在允许范围内。

**注意**：胜率同时反映流派数值和电脑对该流派的操作水平（第 3、4 步就是电脑的问题），它是「有没有明显失衡」的警报，不是精确的强度排名。

## 6. 通用系统公式

**单位**：内部位置和速度都用同一套抽象单位（主平台宽 140），固定 60 帧/秒，渲染时统一缩放。

| 系统 | 公式 / 数值 |
|---|---|
| 击飞量 | `kb = ((((p/10 + p·d/20) · 200/(w+100) · 1.4) + 18) · s + b) · r`。p 是受击后的百分比，d 是本招伤害，w 是体重，s 是成长/100，b 是基础击飞，r 是怒气倍率 |
| 打飞初速 | `kb × 0.03`，之后每帧衰减 0.051；打飞角度在 70°–110° 之间时，硬直期间下落速度统一为 1.8 |
| 硬直 | `floor(kb × 0.4) − 1` 帧；飞行满 **40 帧**且速度低于 2.5 可以空中闪避，满 **45 帧**且速度低于 2.0 可以出空中攻击（防止无限连） |
| 打击停顿 | `floor(d × 0.65 + 6)` 帧，上限 30；打在盾上 ×0.67 |
| 1v1 伤害倍率 | 受到的伤害 ×**1.2**（本作永远是 1v1，所以固定开启） |
| 短跳空中攻击 | 伤害 ×0.85 |
| 重击蓄力 | 最多 60 帧，伤害 ×1.0 → ×1.4 |
| **陈旧招式** | 记录最近 9 次命中的招式，同一招出现在队列第 1–9 位时，分别扣减 9%、8.5%、7.6%、6.8%、5.9%、5.0%、4.3%、3.3%、2.5% 的伤害（累加）；不在队列里的招式伤害 ×1.05。对击飞只按 0.3 的系数生效。打在盾上也会变陈旧（×0.85） |
| **怒气** | 自身百分比从 35% 到 150%，击飞倍率从 1.0 线性增加到 1.1 |
| 盾 | 耐久 50；盾受到的伤害 ×1.19；**按住期间每帧衰减 0.15**，不按时每帧恢复 0.08；盾被打爆后眩晕（百分比越低眩晕越久，连按可以缩短）；收盾 11 帧硬直 |
| 盾硬直 | `伤害 × 0.8 + 2` 帧 |
| 精准防御 | 敌人攻击命中前 5 帧内松开盾：盾不掉耐久，收盾也没有硬直 |
| 盾中出招 | 盾中可以直接出上重击、上必杀、抓、跳跃（接空中攻击），不用先收盾 |
| **台边** | 抓台边时获得无敌：`60 × 滞空帧/300 + 44 − 百分比/120 × 44 + 19`（滞空帧上限 300、百分比上限 120），其中 19 帧是抓台动作本身，结果在 19–123 帧之间；不落地再次抓台，无敌时间依次 ×0.8、×0.5，第三次起没有无敌；**落地前最多抓 6 次台边**；抢台边会把原来挂着的人挤下去；最长挂台 6.5 秒；台边可以起身、起身攻击、翻滚、跳跃、松手 |
| 角色推挤 | 两人身体重叠时推开到刚好接触，走路和冲刺都穿不过去；推到台边为止、不会把人挤下台；翻滚、闪避、抓投中不推 |
| 复活 | 从舞台上方的平台落下，2 秒无敌 |

## 7. 平衡原则（每一条都对应上面的某个数值）

1. **越强越慢**：威力与起手、后摇挂钩。大锤侧重击第 26 帧才出手，下强第 6 帧就出手但击飞弱。几乎所有招式打在盾上都是负帧，被挡住就要准备吃反击。
2. **三方克制**：攻击克抓（抓人的前摇会被打断），抓克盾，盾克攻击；闪避能躲一切，但有后摇并且会衰减。
3. **防守不能无限**：盾一直按着会自己变薄；连续闪避会变慢、无敌帧变短；每次离地只能空中闪避一次；台边无敌会递减，最多抓 6 次。这几条加上**时间上限**，可以防止一直躲、一直挂台边拖时间。
4. **进攻不能无限**：陈旧招式让同一招越用越弱，逼玩家换招；硬直在 40/45 帧后可以取消，防止高击飞时被无限连击。
5. **劣势有翻盘手段**：怒气让百分比高的一方打人更痛；台边无敌公式让「刚被打飞出去、百分比低」的一方更容易回场；复活后 2 秒无敌。
6. **重型流派的取舍**：体重、霸体、多段跳、强力复活，换来的是慢、空速最低、体型大容易被连。所有流派都按「优势要用劣势换」来设计，不做全面更强的流派。

| 🐟 **猫薄荷小镇** | x −74…74 | 一块会动的：高 26、宽 34，中心在 x −45 和 45 之间来回，每帧移动 0.3，到两端各停 90 帧（一个来回 780 帧，13 秒） | ±240 / 195 / −140 | 场地和边界都更大，活得更久；平台带着人移动 |

规则（每一条都写成断言，见 §11 第 23–26 条）：

1. 单人在首页选地图，联机由房主在等待室选地图（和时间上限一样只有房主能改，搭子能看到）。选择会被记住。
2. 奶酪月台上没有薄平台：原地满跳加二段跳后一定落回主平台；站在 x=80 仍在地面上；台边在 ±85。
3. 猫薄荷小镇的移动平台位置只由对局帧数决定（联机双方、快照回放算出来一样）。站在平台上什么都不按，人会跟着平台一起移动；按 S 可以从平台上穿下去；跳上去可以站住。
4. 复活平台、开局站位按各地图的大小放；三张地图上电脑都能正常打完一局，不会因为不认识地图而大量自己掉下去。

## 9. 对局规则

- **每人 3 条命，限时 8 分钟**，可以改成 5 或 12 分钟（联机时由房主决定）。
- **时间到时**：剩余命数多的一方获胜 → 命数相同时百分比低的一方获胜 → 仍相同则进入**决胜局**：双方从 300% 开始，先被打出场外的输。
- 单人模式对战电脑：电脑用内置玩具角色，流派可以指定或随机，难度分四档：木桩（站着不动，用来练招）、轻松、普通、高手。

## 10. 联机（沿用赛车架构）

- 发送方做房主，运行权威模拟（`game/match.cjs`，固定 60 帧/秒）。客人只发**输入**，不上报位置、伤害或命数。
- **按键边沿不能丢**：latest 通道只保留最新一条，所以跳跃、J、K、U、抓这类「按了一下」的动作一律用**累计计数器**发送，由房主比较差值得到按了几次；方向、盾、跳跃键是否按住是持续状态，直接发当前值（短跳和大跳要靠「是否按住」来区分）。
- 客人本地预测自己的移动和出招前摇，对手画面插值显示；**命中与否只以房主为准**。
- 遵守宿主限额：每秒最多 30 次调用、单条消息 ≤60 KB。断线时暂停并显示倒计时，超时则判定对方离开。
- 协议 `{"id":"pet-brawl","version":1}`；HTML 能力声明与赛车相同：`character:read`、`character:watch`、`sessions:connect`。

## 11. 验收条件（先写成断言，再写实现）

每一条都要先写成**由真实输入驱动**的测试（CDP 真实键盘），再实现。纯数值条目在 Node 规则层测。

**形象**
1. 在桌宠里打开并允许授权：带 getRealtime 的宿主上出现 3D 布偶，旧宿主上出现当前桌宠的 2D 立绘。拒绝授权时显示原因和重试按钮，重试成功后换成桌宠形象。
2. 对局中给桌宠换装，自己和对方画面里的角色都会跟着换。
3. 2D 和 3D 角色在同一百分比下吃同一招，飞行距离完全相同。

**操作**
4. 按住 D 向右移动；快速双击 D 进入冲刺；按 S 能从薄平台穿下去。
5. 轻点空格是短跳，按住是大跳，两者高度不同；空中能再跳 4 次。
6. 同时按 W+K 打出上必杀，不会先跳起来。

**战斗**
7. 普攻 1 → 2 → 终结能连起来；每一招的起手帧和伤害与招式表一致（规则层逐招断言）。
8. 用同一招打同一目标，目标百分比越高被打得越远；**每招的实测击杀百分比在目标 ±10% 以内**（规则层跑击杀百分比表）。
9. 同一招连续命中后伤害下降（陈旧招式）；换别的招打几次后恢复。
10. 按住 L 开盾挡攻击，百分比不增加；盾在按住期间会自己变薄；盾被打爆后眩晕。
11. 抓能抓住正在开盾的对手；一口吞能吸入开盾的对手。
12. 闪避的无敌帧内被攻击不受伤害；连续闪避时无敌时间会变短。
13. 蓄力大锤出锤前被小招打中不会被打断（霸体），被大招打中会被打断。
14. 上必杀用完后进入无助下落，落地或抓台前按 J/K 没有反应。
15. 下空锤头中心打中空中的对手，对手向下飞。

**台边与胜负**
16. 被打出边界少一条命，从上方复活并有 2 秒无敌；3 条命用完判负并进入结算。
17. 不落地连续抓台，无敌时间按规则递减；第 7 次抓不住台边。
18. 时间到时按命数、百分比判定胜负；完全平手时进入 300% 决胜局。

**联机与单人**
19. 联机时客人连按 J 五次，房主一次不漏地处理五次。
20. 联机时客人伪造位置或伤害数据会被房主拒收。
21. 客人断线后双方暂停并显示倒计时，超时后提示对方已离开。
22. 单人模式电脑能完整打完一局并进入结算。

**地图（§8）**
23. 首页用键盘选中奶酪月台后开打，对局就在月台上（画面也换成月台）；刷新后仍记住这张图。联机时只有房主能换地图，搭子看到同一张。
24. 奶酪月台：原地满跳加二段跳后落回主平台；走到 x=80 仍站在地面；能抓住 x=85 的台边。
25. 猫薄荷小镇：站在移动平台上不做操作，人和平台移动同样的距离；按 S 从平台穿下；从主平台跳上平台能站住；平台位置只由帧数决定，快照回放后一致。
26. 三张地图上高手电脑都能打完一局，自己掉下去的次数不比毛线篮球场明显多。
