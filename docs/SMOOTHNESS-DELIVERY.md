## 发现与可重放原因

审计发现者为 AI；先从 `game/net.cjs` 提出假设，再用真实模块加确定性 SDK/时钟回放证实。客端在 tick 与每次输入确认后的重放中调用 `M.step` 推进整场预测，然后直接将整场预测送入 `world.update`。远端角色和其弹道因此受本机尚未确认输入数量影响：本机静止，远端仍会周期倒退。

真实隐藏双宿主基线：`artifacts/host-e2e/2026-09-27T13-17-42-704Z/report.json`。真实发送 HTML、首次授权、TLS 配对、准备与 CDP 键盘往返后，普通网络客端远端角色有 **9.48% 反向帧、p95 8.05 倍**；宿主 0% 反向、p95 1.26。增加 180 ms 轮询延迟后，客端反向 4.27%、p95 2.65。该报告的通过表示“缺陷按预期复现”，不是旧版流畅度通过。

## 修复与边界

- `game/remote-motion.cjs` 是纯呈现模块：房主 `match.frame` 建时间轴，150 ms 缓冲、最多 100 ms 外推；新局/阶段/暂停重建，真正进展快照间隔超过 1 秒后重新基准，同身份旧/重复帧先拒绝。
- `game/net.cjs` 增加 `present()`，`src/main.js` 只将其用于世界绘制。原 `live()`、输入重放、碰撞、计分、事件、HUD、自己的角色与自有弹道预测未改。
- 远端弹道按 `id + owner` 关联，所有权变化不混轨迹，不重复呈现本地预测弹道；死亡、复活、剩余生命数变化与大幅传送不跨状态插值。
- 独立审查发现小镇平台的时间轴差：场景按当前预测帧绘制平台，远端绝对位置延迟会脱离平台。真实 `M.step` 站台回放先失败，再补“平台相对坐标”到当前绘制平台的呈现补偿；不改变权威地面或碰撞状态。

首轮普通及批量回放中，角色与真实毛线球均为 0 反向、0 停顿、p95 约 1.0。该指标限指定匀速区间；有限外推在数据长期停滞时明确停住，不承诺任意网络条件下零瞬时跳变。

## 测试修正与预防

首轮修复 E2E `2026-09-27T13-25-50-116Z/report.json` 曾因“反向比例”断言失败，保留失败报告。调查发现，测试只按发出键盘命令后的墙钟窗口选择匀速段；CDP 命令延迟和真实转向减速让 5 个加速/刹车帧混入匀速统计。最终采样同时要求前后帧为 walk 且实际绘制输入速度为方向对应的 1.03 游戏单位/帧（容差 0.01），不按实际位移正负筛选；用同一规则重算修复前后，修复前的倒退仍完整保留，之后重跑真实门禁通过。

转向并未被验收整体排除：纯回放包含全部转向、加速与减速帧，在普通/批到达预期约 183 / 200 ms 呈现延迟下，完整轨迹 RMS 误差分别约 0.088 / 0.177 游戏单位，最大 0.30 / 1.50，断言 RMS < 0.3、最大 < 2。移动平台曾由独立审查发现并先复现失败再修复；后续运动门禁应同时包含时间轴差异的场景依赖，不能只测平地走路。

本轮事实为 macOS 同机隔离双宿主 UDP/TCP/TLS 路径，不冒充实体两台电脑、Windows 或原生焦点/系统合成帧率实测。实体双机体验仍需用户使用重新发送的新 HTML 验收；旧接收文件不会自动升级。
