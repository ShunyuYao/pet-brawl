# 桌宠大乱斗 · Pet Brawl

一个单文件 HTML 的双人平台格斗游戏，给「吐梨邦」桌宠的 HTML 作品能力做的。在桌宠里打开会自动带入你当前的桌宠形象上场；通过桌宠「发送并一起玩」可以和同一局域网的朋友对打，也可以单人挑战电脑。

A single-file HTML platform fighter for the 吐梨邦 desktop pet. Opened inside the pet it fights with your current pet; "send and play together" starts a LAN match with a friend, or play solo against the computer. 8 fighting styles, 3 stages.

交付文件：[`dist/桌宠大乱斗.html`](dist/桌宠大乱斗.html)（约 840 KB，three.js、cannon-es 与全部代码内联，无 CDN、无服务器）。
完整规则、招式表与平衡记录：[docs/SPEC.zh-CN.md](docs/SPEC.zh-CN.md)。

## 玩法

- 被打会累积**伤害百分比**，百分比越高被打得越远，飞出场外就少一条命。每人 3 条命，默认限时 8 分钟（可选 5 / 12）。时间到比剩余命数，再比百分比，仍平手进入 300% 决胜局。
- **形象和流派互不绑定**：任何形象都能选任何流派。

| 流派 | 定位 | 特点 |
|---|---|---|
| 🧀 奶酪大锤 | 重型力量 | 慢但重、复活远，霸体大跳、一口吞、蓄力大锤 |
| 🐾 猫爪拳 | 轻量快攻 | 第 2 帧出手，爪风、猫扑、猫跃、看破反击 |
| 🧶 毛线球法师 | 远程牵制 | 蓄力毛线球、减速缠线、毛线钩、毛线陷阱 |
| 🥷 纸箱忍者 | 灵巧诡变 | 蓄力飞镖、瞬身斩、方向弹射、替身纸箱 |
| 🪶 逗猫棒剑士 | 精准距离 | 只有逗猫棒最远端打中才最痛；逗猫连击、蓄力突刺破盾 |
| 💪 肉垫摔角手 | 投技重炮 | 无视盾的绳索摔；蓄怒接住攻击，下一击加倍 |
| 🥊 拳击喵 | 地面拳王 | 地面出拳最快；挨打攒能量，满了一拳必杀；空中很弱 |
| ⚡ 疾风猫 | 高速爆发 | 跑得最快，膝撞只有第一帧最强，疾风重拳 |

| 地图 | 特点 |
|---|---|
| 🧶 毛线篮球场 | 三块薄平台，空中打法 |
| 🧀 奶酪月台 | 更宽、没有平台，纯地面对拼 |
| 🐟 猫薄荷小镇 | 一块左右来回的木板平台，站上去会被带着走；场地更大，活得更久 |

- **单人**：选电脑难度（木桩 / 轻松 / 普通 / 高手）、电脑的流派、时间上限和地图。普通浏览器也能玩。
- **双人**：发送方是房主，决定时间上限和地图；双方在等待室各自选流派，都点准备后开打。
- 音乐和音效默认打开（第一次点击或按键后开始出声），全部运行时合成。

| 键 | 作用 |
|---|---|
| A / D | 移动，快速双击冲刺 |
| W | 上 / 跳跃（可在「键位」里关掉）；W+J 上强、W+U 上重击、W+K 上必杀 |
| S | 蹲下 · 穿平台 · 快速下落 |
| 空格 | 跳跃：轻点短跳、按住大跳 |
| J | 普通攻击（配合方向） |
| K | 必杀技（随流派不同，「键位」面板里会显示当前流派的四个必杀） |
| U | 重击，按住蓄力 |
| L | 盾；盾+方向闪避；空中闪避 |
| I（或 L+J） | 抓人，抓住后按方向投 |

手柄：左摇杆移动，Ⓐ 跳、Ⓧ 攻击、Ⓨ 必杀、RB 重击、LB 盾、RT 抓。`` ` `` 键显示判定框（调试）。

## 形象从哪里来

| 来源 | 结果 |
|---|---|
| 桌宠当前形象（自动，需授权「读取当前宠物形象」） | 2D 立绘 |
| 宿主支持 `pet.character.getRealtime()` 且形象带实时布偶数据 | 3D 布偶，被重击打飞时物理翻滚 |
| 手动导入角色包 ZIP / 文件夹 / PNG / WebP / JPG | 3D 或 2D |
| 内置 | 奶酪鼠 / 橘子猫 / 棉花兔 |

2D 和 3D 共用同一套判定：受击范围只由流派决定，与形象无关。导入的形象只保存在本作品的浏览器存储里，联机时经宿主的会话通道发给对方一次，不上传任何服务器。

## 联机

房主权威：房主运行规则（`game/room.cjs`、`game/match.cjs`，固定 60 帧/秒），客人只发操作；「按了一下」的动作用累计计数器发送，不会因为只保留最新一条而丢键。客人本地预测自己的动作并向房主结果收敛。使用宿主 `pet.sessions`（协议 `pet-brawl` v1，2 人）。

客端显示其他玩家及其弹道时，按房主帧时间平滑呈现，避免本地输入确认造成远端反复跳回；自己操作的预测与房主战斗判定保持独立。已发送的旧 HTML 不会自动替换，需重新发送新的 `dist/桌宠大乱斗.html` 才使用修复版。调查与证据见 [联机运动呈现审计](docs/SMOOTHNESS-DELIVERY.md)。

## 开发

```sh
npm run build          # esbuild 打包成单个内联脚本（可用 PET_BRAWL_ESBUILD 指定 esbuild 路径）
npm run test:rules     # 规则、招式、姿势、击杀百分比、地图与联机协议（Node，335 条）
npm run test:poses     # 八流派四向必杀的姿势与网络快照回归
npm run test:freeze    # 法师缠线：真实键盘、画面与计时持续更新
npm run calibrate      # 改了招式伤害、角度、帧数或击杀目标后，重新反推击飞参数
npm run balance        # 高手电脑八个流派两两对打，每组 200 局，胜率须在 25%–75%
npm run test:browser   # 隐藏 Electron 打开最终 HTML，CDP 真实键盘
npm run test:host      # 两个真实桌宠宿主实例的局域网 E2E（需要宿主源码与本地角色包）
npm run test:host:freeze # 法师缠线的双宿主局域网专项（已包含在 test:host）
npm run test:motion     # 实际网络回放、弹道、暂停与移动平台边界（已包含在 test:rules）
npm run test:host:smoothness # 双宿主实际绘制轨迹、反向帧与抖动（已包含在 test:host）
```

浏览器与宿主 E2E 需要本地角色包夹具（带实时布偶数据的 `rat-doll-*.zip`，不随仓库发布）：用 `BRAWL_DOLL_ZIP`、`BRAWL_IMAGE`、`BRAWL_PACKS_DIR`、`BRAWL_HOST_ROOT` 指定。

## 目录

- `game/`：纯规则（公式、八个流派的招式表与标定出的击飞参数、对局模拟、地图、击杀百分比测量、电脑、房间、联机适配、单人驱动）。
- `tools/`：击飞参数标定、流派胜率、单局模拟。
- `src/`：three.js 场景与特效、形象（3D 布偶 / 2D 立绘 / 玩具）、武器、招式姿势、角色导入、合成音效、界面。
- `vendor/lib/`：three.js 0.164.1、cannon-es 0.20.0（MIT）。`vendor/doll/`：[pet-ragdoll-renderer](https://github.com/ShunyuYao/pet-ragdoll-renderer) 0.2.0（MIT），改动见其中 NOTICE。

所有声音运行时合成，没有录音素材；仓库不含任何头像、照片或角色贴图。
